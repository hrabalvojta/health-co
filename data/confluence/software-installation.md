# Software Installation Guide — EuroHealth Insurance AG

## Approved Software

### Self-Service (No Approval Needed)
These applications can be installed directly from the Software Center:
- Microsoft Office 365 (Word, Excel, PowerPoint, Teams)
- Adobe Acrobat Reader
- 7-Zip
- Notepad++
- Google Chrome / Mozilla Firefox
- Microsoft Visual Studio Code
- Zoom Client

### Approval Required
The following require manager approval via ServiceNow:
- Adobe Creative Suite
- Visio / Project
- Development tools (Docker, Python, Node.js)
- Any software not on the approved list

## How to Install via Software Center

### Windows
1. Open "Software Center" from Start menu
2. Browse the "Applications" tab
3. Select the application you need
4. Click "Install"
5. Installation completes within 10–15 minutes

### macOS
1. Open "Self Service" application
2. Browse available applications
3. Click "Install" next to your selection
4. Enter your admin password when prompted

## Requesting New Software
1. Go to ServiceNow: https://eurohealth.service-now.com
2. Click "Request Something" → "Software Request"
3. Fill in:
   - Software name and version
   - Business justification
   - Your manager's name (for approval routing)
4. Typical approval time: 2–3 business days
5. After approval, software appears in Software Center

## Troubleshooting
- **"Installation failed"**: Restart your computer and try again
- **"Insufficient permissions"**: Contact IT Support for admin elevation
- **Software not in catalog**: Submit a ServiceNow request (see above)
